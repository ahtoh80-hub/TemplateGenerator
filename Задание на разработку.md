## 1. Общее описание

Программа предназначена для автоматической генерации множества TXT-файлов на основе шаблона и данных из Excel-файла. В шаблоне производятся замены тегов на новые значения, соответствующие каждому экземпляру (LOOP).

### 1.1 Основная задача

На вход подается:
- **Шаблон** (TXT-файл) - содержит код, в котором нужно заменить определенные теги
- **Excel-файл** - содержит список экземпляров и новые значения тегов для замены

На выходе получается множество TXT-файлов (по количеству экземпляров), где в каждом выполнены замены тегов согласно данным из Excel. Также создается файл "История замен.txt" с полным отчетом о всех произведенных заменах.

### 1.2 Целевая аудитория

Инженеры-программисты АСУ ТП, занимающиеся настройкой и конфигурированием SCADA-систем.

## 2. Функциональные требования

### 2.1 Загрузка шаблона (ТЗ п.2)
- **Формат:** TXT-файл, XML-файл
- **Действие:** Пользователь через интерфейс выбирает файл шаблона
- **Отображение:** Содержимое шаблона отображается в области предпросмотра
- **Кнопка:** "📁 Загрузить шаблон"
- **Горячая клавиша:** Ctrl+O
- **Логирование:** Запись в лог при успешной загрузке с указанием типа файла

### 2.2 Таблица замен (ТЗ п.3)
- **Количество позиций:** Начинается с 10 позиций + 1 пустая строка в конце
- **Автоматическое расширение:** При заполнении последней строки автоматически добавляется новая пустая
- **Структура таблицы:**

| № | Имя тега для поиска | Использовать |
|---|-------------------|--------------|
| 1 | _вводится пользователем_ | ☑ |
| 2 | _вводится пользователем_ | ☑ |
| ... | ... | ... |
| N | _вводится пользователем_ | ☑ |
| N+1 | (пустая строка) | ☐ |

- **Правила заполнения:**
  - Поле "Имя тега для поиска" - вводится вручную или автоматически
  - Поле "Использовать" - отметка галочкой (CheckBox)
  - Если поле не заполнено - не используется
  - Должно быть заполнено хотя бы одно поле
  - Цвет текста в таблице - черный
  - Таблица должна иметь вертикальный ползунок (ScrollBar)
  - Всегда должна быть пустая строка в конце для добавления новых тегов

- **Нумерация:** Позиции нумеруются последовательно
- **Соответствие Excel:** Номер позиции соответствует столбцу "№ позиции для замены" в Excel

### 2.3 Загрузка Excel-файла (ТЗ п.4)
- **Формат:** XLSX
- **Структура файла:**

| A (LOOP) | B (Tag No) | C (№ позиции для замены) |
|----------|------------|--------------------------|
| 2120-XZV-00204 | 2120-XZV-00204 | 1 |
| 2120-XZV-00204 | 2120-XZY-00204 | 2 |

- **Описание столбцов:**
  - **Столбец A (LOOP):** Имя экземпляра (используется для именования выходных файлов)
  - **Столбец B (Tag No):** Новый тег для замены
  - **Столбец C (№ позиции для замены):** Номер позиции (1-10), соответствует номеру в таблице замен

- **Действие:** Пользователь выбирает Excel-файл через интерфейс
- **Кнопка:** "📊 Загрузить экземпляры"
- **Горячая клавиша:** Ctrl+E
- **Логирование:** Запись в лог количества загруженных строк и экземпляров

### 2.4 Информационная панель (ТЗ п.4, п.11)
- **Расположение:** Справа на форме
- **Заголовок:** "Детали замен по экземплярам" (выше окна информации) - **белый текст на синем фоне**
- **Возможность изменения ширины:** Разделитель (Splitter) между панелью предпросмотра и информационной панелью
- **Ползунки:** Вертикальный и горизонтальный для прокрутки содержимого
- **Содержание:**
  1. Список всех экземпляров с их заменами по позициям
  2. Каждый экземпляр отображается в формате:
     ```
     Экземпляр: 2120-XZV-00204
       Позиция 1: _2120_XZY_00204 -> _2120-XZV-00204
       Позиция 2: _2120_XZV_00204 -> _2120-XZY-00204
     ---------------------------------------------------
     ```
  3. Статистика (количество экземпляров, позиций, замен)
  4. Индикация активного режима преобразования тегов
  5. **Визуальное выделение:** Вторая часть тега (буквенная часть) выделяется красным цветом, если она не совпадает с соответствующей частью тега в таблице замен для данной позиции

- **Формат отображения:** RTF-текст с использованием моноширинного шрифта (Consolas)
- **Обновление:** Автоматически при загрузке данных и изменении таблицы замен

### 2.5 Предпросмотр шаблона (ТЗ п.5)
- **Расположение:** Центральная часть формы
- **Отображение:** Полное содержимое загруженного шаблона
- **Форматирование:** Моноширинный шрифт (Consolas)
- **Ползунки:** Вертикальный и горизонтальный
- **Обновление:** Автоматически при загрузке нового шаблона

### 2.6 Преобразование тегов (ТЗ п.8, п.11)
- **Название кнопки:** "🔄 Преобразовать тэг"
- **Функция:** Замена символа "-" на "_" во всех тегах из Excel
- **Пример:** `2713-XZV-01001` → `2713_XZV_01001`
- **По умолчанию:** ВКЛЮЧЕНО при запуске программы
- **Действие:** Включается/выключается кнопкой
- **Горячая клавиша:** Ctrl+T
- **Визуальная индикация:**
  - ВКЛ: зеленая кнопка, текст "🔄 Преобразование ВКЛ (→ _)"
  - ВЫКЛ: желтая кнопка, текст "🔄 Преобразовать тэг"
- **Отображение:** Изменения видны в деталях замен справа
- **Применение:** Преобразование применяется при генерации файлов
- **Логирование:** Запись в лог при включении/выключении режима

### 2.7 Генерация файлов (ТЗ п.6)
- **Действие:** Создание TXT-файлов для каждого экземпляра
- **Количество:** Равно количеству экземпляров в Excel
- **Имена файлов:** Имя экземпляра (LOOP) + расширение (совпадает с расширением шаблона)
- **Тип файлов:** Определяется по расширению шаблона (.txt, .xml, .csv, .json), по умолчанию .txt
- **Обработка дубликатов:** Если файл с таким именем существует, добавляется суффикс `_1`, `_2` и т.д.
- **Папка:** Пользователь выбирает папку для сохранения
- **Кнопка:** "🚀 Сгенерировать" (оранжевая)
- **Горячая клавиша:** Ctrl+G
- **Логирование:** Запись в лог процесса генерации и результата

### 2.8 Сохранение истории замен
- **Действие:** При каждой генерации создается/дополняется файл "История замен.txt"
- **Расположение:** В той же папке, куда генерируются выходные файлы
- **Структура файла:**
  ```
  ====================================================================================================
  Дата и время: 2026-08-10 15:30:45
  Количество сгенерированных файлов: 11
  Активных позиций замен: 2
  Преобразование тегов: ВКЛ (→ _)
  Тип выходных файлов: *.txt
  ====================================================================================================
  
  ДЕТАЛИ ЗАМЕН ПО ЭКЗЕМПЛЯРАМ:
  --------------------------------------------------------------------------------
  Экземпляр: 2120-XZV-00204
    Позиция 1: _2120_XZY_00204 -> _2120-XZV-00204
    Позиция 2: _2120_XZV_00204 -> _2120-XZY-00204
  --------------------------------------------------------------------------------
  ```
- **Режим:** Дополнение (append) - каждая новая запись добавляется в конец файла
- **Разделитель:** Каждая запись отделяется пустой строкой и линией из символов "="
- **Логирование:** Запись в лог о сохранении истории

### 2.9 Проверка данных
- **Действие:** Проверка корректности заполнения
- **Проверяет:**
  - Наличие активных позиций для замены
  - Загрузку шаблона
  - Загрузку Excel
  - Наличие замен для всех позиций
- **Отображение:** Сообщение с результатами проверки
- **Кнопка:** "✅ Проверить" (зеленая)
- **Горячая клавиша:** Ctrl+V (вне таблицы замен)
- **Логирование:** Запись результатов проверки

### 2.10 Очистка всех данных (ТЗ п.10)
- **Действие:** Полная очистка всех данных
- **Очищает:**
  - Шаблон (текст и путь)
  - Excel данные (экземпляры)
  - Таблицу замен
  - Информационную панель
  - Сбрасывает режим преобразования на ВКЛ
  - Очищает лог событий
- **Подтверждение:** Запрос подтверждения перед очисткой
- **Кнопка:** "🗑 Очистить все" (красная)
- **Горячая клавиша:** Ctrl+C (вне таблицы замен и текстовых полей)
- **Логирование:** Запись в лог факта очистки

### 2.11 Окно событий и ошибок (ТЗ п.12)
- **Расположение:** Внизу формы
- **Назначение:** Отображение всех событий и ошибок в реальном времени
- **Содержание:**
  - Успешные операции (загрузка файлов, генерация)
  - Предупреждения (отсутствие замен)
  - Ошибки (с подробным описанием)
- **Формат:** Список с временными метками
- **Цветовая индикация:**
  - Информация: белый/светлый текст
  - Успех: зеленый текст
  - Предупреждение: желтый текст
  - Ошибка: красный текст
  - Процесс: голубой текст
  - Действие: белый текст
- **Автопрокрутка:** При добавлении новых сообщений
- **Ограничение:** Максимум 1000 сообщений
- **Копирование/Вставка:** Поддерживается Ctrl+C и Ctrl+V

### 2.12 Контекстное меню (ТЗ п.7)

- **Содержание:**

  - 📊 Загрузить экземпляры
  - Разделитель
  - ✅ Проверить
  - 🔄 Преобразовать тэг
  - 🚀 Сгенерировать
  - Разделитель
  - 🗑 Очистить все
  - Разделитель
  - 📋 Копировать (Ctrl+C)

  - ✂️ Вырезать (Ctrl+X)
  - 🗑 Очистить (Delete)

- **Расположение:** Верхняя часть окна
- **Разделы:**
  - **📁 Файл**

### 2.14 Автоматическая идентификация тегов (ТЗ п.13)
- **Действие:** Автоматическое определение тегов в шаблоне
- **Формат тега:** `_цифры_буквы_цифры+буквы`
- **Правила:**
  - **Первая часть:** только цифры (1-6 символов) - номер оборудования/системы
  - **Вторая часть:** только английские буквы (1-10 символов) - функциональное обозначение
  - **Третья часть:** начинается с цифры (1-10 символов), затем любые буквы/цифры - номер тега
- **Поиск тегов с 3-мя и более частями:** 
  - Находятся теги с 3-мя частями (`_цифры_буквы_цифры+буквы`)
  - Находятся теги с 4-мя и более частями, но берется только 3 части (4-я и далее игнорируются)
- **Игнорирование:** Теги с точкой (`.`) внутри не находятся
- **Уникальность:** Повторяющиеся теги не включаются в перечень
- **Заполнение:** Найденные теги заносятся в таблицу с присвоением номера по порядку
- **Пустая строка:** Всегда добавляется пустая строка в конце для новых тегов

### 2.15 Копирование/Вставка в таблице замен
- **Действие:** Возможность копировать и вставлять данные в таблице замен
- **Горячие клавиши:**
  - `Ctrl+C` - копирование выделенных ячеек
  - `Ctrl+V` - вставка данных из буфера обмена
  - `Ctrl+X` - вырезание выделенных ячеек
  - `Delete` - очистка выделенных ячеек
- **Формат данных:** Таблица с разделителями табуляции
- **Логирование:** Запись в лог действий копирования/вставки

### 2.16 Копирование/Вставка в текстовых полях
- **Действие:** Стандартное копирование/вставка текста
- **Поля:**
  - Предпросмотр шаблона (txtTemplatePreview)
  - Детали замен по экземплярам (txtMappingInfo)
  - Окно событий и ошибок (rtbLog)
- **Горячие клавиши:**
  - `Ctrl+C` - копирование текста
  - `Ctrl+V` - вставка текста
  - `Ctrl+A` - выделить весь текст

### 2.17 Добавление подчеркивания к тегам замены
- **Правило:** Если тег для поиска начинается с "_", то тег замены автоматически получает "_" в начале
- **Пример:** `_2120_XZY_00204` (поиск) → `_2120-XZV-00204` (замена)

### 2.18 Поддержка XML
- **Действие:** При генерации XML-файлов автоматически обновляется атрибут NAME
- **Правило:** Атрибут `NAME="..."` заменяется на `NAME="имя_экземпляра"`
- **Пример:** `NAME="template"` → `NAME="2120-XZV-00204"`
- **Применение:** Только для файлов с расширением .xml

### 2.19 Визуальное выделение несовпадающих тегов
- **Действие:** В информационной панели выделяется красным цветом вторая часть тега замены, если она не совпадает со второй частью тега поиска в той же позиции
- **Сравнение:** Для каждой позиции отдельно сравнивается вторая часть (буквенная часть между подчеркиваниями)
- **Пример:**
  ```
  Позиция 1: _2120_XZV_00204 -> _2120_XZV_00204  (без выделения - совпадает)
  Позиция 1: _2120_XZV_00204 -> _2120_XZY_00204  (красное выделение - не совпадает)
  ```
- **Формат:** RTF-текст с использованием красного цвета (`\cf1 ... \cf0`)

### 2.20 Адаптивная панель кнопок
- **Действие:** Кнопки в нижней панели автоматически адаптируются к ширине формы
- **Реализация:** Использование FlowLayoutPanel с переносом на новую строку
- **Поведение:**
  - При достаточной ширине - все кнопки в одной строке
  - При уменьшении ширины - кнопки переносятся на следующую строку
  - Нет фиксированных позиций
  - Минимальные размеры кнопок для сохранения читаемости

### 6.2 Алгоритм автоматического определения тегов
```
1. Поиск всех тегов по паттерну: _цифры_буквы_цифры+буквы
2. Проверка каждой части:
   - Первая часть: только цифры (1-6 символов) - номер оборудования
   - Вторая часть: только английские буквы (1-10 символов) - функциональное обозначение
   - Третья часть: начинается с цифры (1-10 символов), затем буквы/цифры - номер тега
3. Поиск тегов с 3-мя и более частями
4. Если тег имеет 4-ю и более части - они игнорируются (отбрасываются)
5. Удаление дубликатов (уникальные теги)
6. Заполнение таблицы найденными тегами
7. Добавление пустой строки в конце
8. Присвоение номеров позиций по порядку
9. Добавление записи в лог о количестве найденных тегов
```

### 6.3 Алгоритм генерации файлов
```
Для каждого экземпляра в instances:
1. Создать копию templateContent
2. Для каждой активной позиции замены:
   а. Найти searchTag в копии
   б. Если searchTag начинается с "_", добавить "_" к replaceTag (если нет)
   в. Если включено преобразование → применить ConvertDashToUnderscore
   г. Заменить все вхождения searchTag на replaceTag
3. Если выходной файл XML → обновить атрибут NAME
4. Определить расширение выходного файла по шаблону
5. Сохранить результат в файл {InstanceName}.{extension}
6. Добавить запись в лог: "📄 Создан файл: {InstanceName}.{extension}"

После генерации всех файлов:
1. Сформировать отчет в формате:
   - Дата и время генерации
   - Количество сгенерированных файлов
   - Активные позиции замен
   - Состояние преобразования тегов
   - Тип выходных файлов
   - Детали замен для каждого экземпляра
2. Сохранить отчет в файл "История замен.txt" (режим дополнения)
3. Добавить запись в лог: "✅ История замен сохранена"
```

### 6.4 Алгоритм визуального выделения тегов
```
Для каждого экземпляра и каждой позиции:
1. Получить searchTag из таблицы замен
2. Получить replaceTag из Excel
3. Извлечь вторую часть из searchTag (буквенная часть между подчеркиваниями)
4. Извлечь вторую часть из replaceTag
5. Сравнить вторые части (без учета регистра)
6. Если не совпадают → выделить вторую часть replaceTag красным цветом в RTF
7. Если совпадают → отобразить без выделения
```

## 7. Сценарии использования

### 7.1 Базовый сценарий
1. Пользователь запускает программу
2. В логе появляется сообщение "ℹ️ Программа запущена"
3. Преобразование тегов включено по умолчанию
4. Нажимает "📁 Загрузить шаблон" и выбирает TXT-файл
5. В логе: "✅ Шаблон загружен: example.txt" и "ℹ️ Тип шаблона: *.txt"
6. Происходит автоматическое определение тегов (находятся теги с 3-мя частями, 4-я игнорируется)
7. В таблице замен заполняются позиции + пустая строка в конце
8. При необходимости пользователь корректирует таблицу (можно копировать/вставлять)
9. При заполнении последней строки автоматически добавляется новая
10. Нажимает "📊 Загрузить экземпляры" и выбирает XLSX-файл
11. В логе: "✅ Excel файл загружен: data.xlsx (22 строки)"
12. Справа отображается информация о заменах с выделением несовпадающих тегов
13. При необходимости включает/выключает "🔄 Преобразовать тэг"
14. Нажимает "✅ Проверить" для проверки данных
15. Нажимает "🚀 Сгенерировать"
16. Выбирает папку для сохранения
17. Получает готовые файлы (тип соответствует шаблону)
18. В логе: "✅ Успешно сгенерировано 11 файлов"
19. В логе: "✅ История замен сохранена: История замен.txt"
20. В папке с файлами появляется "История замен.txt" с отчетом

### 7.2 Сценарий с автоматическим добавлением строк
1. Пользователь заполняет все позиции в таблице замен
2. При заполнении последней строки автоматически добавляется новая пустая
3. Пользователь может продолжать добавлять теги
4. Количество позиций не ограничено

### 7.3 Сценарий с изменением ширины правой панели
1. Пользователь наводит курсор на разделитель между панелями
2. Курсор меняется на двустороннюю стрелку
3. Перетаскивает границу для изменения ширины
4. Содержимое автоматически перестраивается

### 7.4 Сценарий с адаптивными кнопками
1. Пользователь изменяет ширину окна
2. Кнопки автоматически перестраиваются
3. При достаточной ширине - все кнопки в одной строке
4. При недостаточной ширине - кнопки переносятся на следующую строку

### 7.5 Сценарий с выделением несовпадающих тегов
1. Пользователь загружает шаблон с тегом `_2120_XZV_00204`
2. Загружает Excel с данными
3. В информационной панели видит:
   ```
   Экземпляр: 2120-XZV-00204
     Позиция 1: _2120_XZV_00204 -> _2120_XZV_00204  (без выделения)
   ```
4. Если в Excel указано `_2120_XZY_00204`:
   ```
   Экземпляр: 2120-XZV-00204
     Позиция 1: _2120_XZV_00204 -> _2120_XZY_00204  (XZY - красным)
   ```
5. Пользователь сразу видит, где есть несоответствия

## 13. Примечания к разработке

1. **EPPlus License:** Для коммерческого использования требуется лицензия, для некоммерческого - бесплатно
2. **Кодировка:** Все файлы сохраняются в UTF-8 для поддержки кириллицы
3. **Обработка дублей:** При совпадении имен файлов добавляется суффикс `_1`, `_2` и т.д.
4. **Регулярные выражения:** Используются для безопасной замены тегов с экранированием спецсимволов
5. **Лимит лога:** Максимум 1000 сообщений для производительности
6. **Потокобезопасность:** Все операции выполняются в UI-потоке
7. **Уникальность тегов:** Повторяющиеся теги не добавляются в таблицу замен
8. **Управление горячими клавишами:** При фокусе в таблице или текстовых полях горячие клавиши MenuStrip отключаются
9. **История замен:** Файл "История замен.txt" создается в папке с выходными файлами и дополняется при каждой генерации
10. **Пустая строка:** Всегда есть пустая строка в конце таблицы для добавления новых тегов
11. **Преобразование тегов:** По умолчанию включено при запуске программы
12. **Тип выходных файлов:** Определяется по расширению шаблона
13. **Splitter:** Разделитель между панелями позволяет изменять ширину правой панели
14. **Поиск тегов:** Находятся теги с 3-мя и более частями, 4-я и далее игнорируются
15. **RTF-форматирование:** Информационная панель использует RTF для выделения несовпадающих тегов красным цветом
16. **Сравнение тегов:** Для каждой позиции отдельно сравнивается вторая часть тега (буквенная часть)
17. **Поддержка XML:** При генерации XML автоматически обновляется атрибут NAME
18. **Адаптивные кнопки:** Использование FlowLayoutPanel для автоматического перестроения кнопок
19. **Цвет заголовка:** "Детали замен по экземплярам" - белый текст на синем фоне
